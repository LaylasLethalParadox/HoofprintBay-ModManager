Mod Manager 1.1.0 for Horses of Hoofprint Bay.

New in this version:

- Every mod in the list has an On/Off checkbox, for BepInEx plugins and for custom tack, clothes and language packs. A switch takes effect the next time you start the game, and until then the mod's line says "on after a restart" or "off after a restart". Plugins you switch off stay in the list, so you can switch them back on. The list warns you when a plugin needs another plugin that is off. If a switch fails, for example because a file is in use, the game shows a message with the reason. Mod Manager can't switch itself off.
- A Folders section at the top of the list shows where your plugins and your tack, clothes and language files are, with an Open folder button for each. Click the Folders heading to fold it away.

Other changes:

- Mod Manager's own settings no longer have a Reset to defaults button.
- The list of custom packs is read each time you open the Mods window, so it matches the files on disk.

Requires BepInEx 6 bleeding edge build 793 (IL2CPP, Windows x64); BepInEx 5 can't load this game. To update, extract the zip into the game folder and replace the old `ModManager.dll`. The README has the full install steps.
