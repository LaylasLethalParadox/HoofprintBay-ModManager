First release of Mod Manager for Horses of Hoofprint Bay.

Adds a Mods sign to the main menu and a Mods button to the pause menu. The window lists your BepInEx plugins and custom tack, clothes and language files, and shows every mod's settings with the game's own controls.

Requires BepInEx 6 bleeding edge build 793 (IL2CPP, Windows x64); BepInEx 5 can't load this game. To install, extract the zip into the game folder. The README has the full steps, including what mod authors need to do.
