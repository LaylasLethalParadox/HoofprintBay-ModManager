Mod Manager 1.2.0 for Horses of Hoofprint Bay.

New in this version: a mod that draws its own settings page can now add a box where you type a whole number. Skip Training 1.1.0 uses it for its lesson settings and needs this version.

Requires BepInEx 6 bleeding edge build 793 (IL2CPP, Windows x64); BepInEx 5 can't load this game. To update, extract the zip into the game folder and replace the old `ModManager.dll`. The README has the full install steps.
